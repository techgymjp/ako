## 日本語（ja-JP）

### アプリ名（30文字以内）
```
忠臣蔵 赤穂浪士の討ち入り｜侍チャンバラ剣戟
```

### 簡単な説明（80文字以内）
```
雪の夜、大石内蔵助となって吉良邸へ討ち入れ。指でなぞって斬る3D侍アクション。一太刀で決まる真剣勝負！
```

### 詳しい説明（4000文字以内）
```
元禄十五年十二月十四日、雪の江戸。
赤穂浪士の筆頭・大石内蔵助となり、主君の仇・吉良上野介の屋敷へ討ち入れ。

「忠臣蔵 赤穂浪士の討ち入り」は、画面を指でなぞって刀を振るう3Dの剣戟（チャンバラ）アクションゲームです。
表門から奥の炭部屋まで、史実の吉良邸の間取りを再現した屋敷を進み、立ちはだかる吉良家の家臣を斬り伏せて、夜明けまでに本懐を遂げましょう。

■ なぞった向きに刀が走る
右へなぞれば横一文字、下から上へなぞれば斬り上げ、上から下へなぞれば唐竹割り。
フリックした向きのとおりに、大石内蔵助が踏み込んで斬りつけます。二人、三人とまとめて斬れば連斬の大技に。

■ 一太刀で終わる真剣勝負
斬られたらそこで終わり。敵の刀が赤く光ったら、振り下ろされる前に先に斬るか、金の矢印の向きに「返し技」で斬り返せ。
敵の構え（受け）と同じ向きに斬ると弾かれ、むやみに振り回すと太刀筋が乱れます。見切る目と冷静さが勝負を分けます。

■ 名だたる剣客との一騎打ち
吉良家家老・小林平八郎、山吉新八郎、剣の達人・清水一学。史実に名を残す強敵が行く手を阻みます。
槍の使い手、フェイントをかける剣客など、敵ごとに違う戦い方を見抜け。

■ 同志を守り、夜明けまでに
共に討ち入った同志が斬られそうになったら「助太刀！」。全員そろって生還すれば大きな得点に。
夜明けまでの時間は7分。急ぎつつも、焦れば斬られる。

■ 得点とランキング
早業、剣技、返し技、太刀筋の正確さで得点が決まります。端末内のランキングで自己ベストを更新しよう。
上級者でもなかなかクリアできない手ごたえのある難しさです。

■ こんな人におすすめ
・忠臣蔵、赤穂四十七士、時代劇、日本の歴史が好きな人
・侍、刀、剣術、チャンバラのゲームを遊びたい人
・フルーツを斬るような爽快なフリック操作のゲームが好きな人
・短い時間で遊べる、歯ごたえのあるアクションゲームを探している人

※ 本作には刀による流血の表現があります。
※ 無料で遊べます。広告が表示されます。斬られたときは広告を見て、その戦いからやり直せます。

3Dモデル：“Japanese Clothes” by Takeru ／ “Katana Samurai (game ready asset)” by Pixel Life（CC BY 4.0, Sketchfab）
```

## そのほかの設定の目安

| カテゴリ | アクション |

| 無料／有料 | 無料 |
| 広告 | 含む（AdMob） |
| プライバシーポリシー | https://techgym.jp/privacy-policy/ |
| コンテンツのレーティング（IARC） | 暴力：刀による流血あり（人間への暴力）。区分はアンケートの回答で決まる（12〜16歳以上になる見込み） |
| ターゲット年齢層 | 13歳以上（子ども向けにしない。広告SDKの設定と合わせる） |
| データ セーフティ | AdMob が「デバイスまたはその他の ID」「アプリの操作」「診断情報」を広告・分析の目的で収集・共有（転送時は暗号化）。ゲーム自体は個人情報を集めない。ランキングは端末内だけに保存 |

### ASO のポイント
- アプリ名に「忠臣蔵」「赤穂浪士」「討ち入り」「侍」「チャンバラ」「剣戟」を入れ、検索されやすい語を先頭に置いています。
- 簡単な説明には「大石内蔵助」「吉良邸」「3D」「侍アクション」を入れています。
- 詳しい説明では、「四十七士」「時代劇」「刀」「剣術」「歴史」「フリック」など関連語を、不自然に並べず文章の中で使っています（同じ語の詰め込みはGoogle Playのポリシー違反になるため）。
- 英語版は「47 Ronin」「Samurai」「Sword」「Katana」で探す人を狙っています。「Chūshingura」は海外では知名度が低いため、アプリ名の先頭は「47 Ronin」にしています。
- スクリーンショットは1枚目〜3枚目で「操作（なぞって斬る）」と「緊張感（赤く光ったら返せ）」が伝わる順にしています。
