# 忠臣蔵 赤穂浪士の討ち入り

雪の夜、大石内蔵助となって吉良邸に討ち入る3D剣戟ゲームです（ブラウザで動作）。

## 遊び方

- 進行は自動です。表門から玄関・槍の間・広間・奥の間・上野介寝所・中の間・土間を経て、炭部屋へと進みます。
- **斬る**：敵の身体をなぞるように画面をフリックします（マウスならドラッグ）。なぞった向きに大石が刀を振ります。
  - 右へフリック → 横一文字、下から上 → 斬り上げ、上から下 → 唐竹割り、斜め → 袈裟斬り／逆袈裟
  - 一振りで複数の敵をなぞると「二人斬り」「三人斬り」
  - 速く大きくフリックすると「剛斬」（強敵に2倍の傷）
- **受け**：刀を構えた敵には点線と「受」の表示が出ます。その向きと同じ向きに斬ると弾かれ、すぐ反撃が来ます。
- **一太刀**：刀が赤く光り、赤い輪が縮んだら斬りかかってくる合図です。斬られたらゲームオーバーなので、先に斬ってください。
- 最後に炭部屋で吉良上野介を斬れば本懐成就です。
- キーボードでは矢印キー（またはWASD）で、一番近い敵をその向きに斬れます。Esc／Pで一時停止します。

## 言語

日本語と英語に対応しています。ブラウザの言語設定で自動的に切り替わり、タイトル画面の「English／日本語」ボタンでも切り替えられます（`?lang=en` を付けて開いても英語になります）。英語版でも台詞の音声は日本語のままです。

## 駆け引き

- **返し技**：敵が振りかぶると、斬ってくる向きが赤い矢印で出ます。矢印が金色になった瞬間に逆向きへなぞると、受け流して反撃します（槍の突きは横に払う）。
- **敵の型**：構えを途中で変える剣客、振りかぶって途中でやめるフェイント、遠い間合いから突く槍。
- **夜明けまで7分**：時間が進むと空が白み、夜が明けると失敗です。
- **同志を守る**：同志と斬り結ぶ敵が振りかぶると「助太刀！」と出ます。放っておくと同志が手傷を負い、二度斬られると倒れます。全員生還で大きな得点。
- **得点**：斬った数・連斬・剛斬・返し技・早業・同志の生還・夜明けまでの余裕で加点、やり直しで減点。上位10件をこの端末に保存します。

## 動き・音

- **斬撃モーション**：肩・肘の2関節で両手が柄を握り、振りかぶり → 斬り込み → 残心 → 構えに戻る、の4段階で振ります。なぞった向きで型が変わり（唐竹割り・袈裟斬り・横一文字・斬り上げ）、腰の捻りと踏み込みが付きます。横に斬るときは足を大きく開いて腰を深く落とします。
- **BGM**：尺八・箏・和太鼓・締太鼓を都節音階で合成し、場面（タイトル／進軍／戦闘／吉良発見／本懐成就／無念）ごとに曲が切り替わります。
- **声**：掛け声・悲鳴・怒声は声道（フォルマント）を模した合成音です。「かかれーっ！」「曲者！」「吉良上野介、覚悟！」「えい、えい、おう！」はブラウザの日本語音声合成で発声します（日本語の声が入っていない端末では鳴りません）。

## モーションキャプチャ

Mixamo（Adobe）のモーションを、FBXから関節の位置だけを書き出した軽いデータ（`assets/mocap/*.json`、1本20〜70KB）に変換し、着物を着た人物の骨格に移し替えて再生しています（`js/mocap.js`）。

- 大石の横斬り：4種類（両手の大薙ぎ、片手の大薙ぎ、回転斬り、往復斬り）。フリックの向きに合うものを選ぶ（両手の斬撃は左右反転も使う）
- 大石の振り下ろし：上段に振りかぶって斬り下ろす（Standing Melee Attack Downward）
- 構え：Great Sword Idle を日本刀の中段に補正
- 斬られた敵：縦に斬られたら前へ崩れ落ち、斬り上げられたら仰向けに倒れる。一太刀で倒れない強敵はのけぞる
- 炭部屋の吉良：片膝をついて頭をかばい震える
- 斬り上げ・敵の振りかぶりと受けの構え・歩きは、これまでどおり手作りの動きを使います

## 屋敷の再現

`js/world.js` の `ROOMS` に、吉良邸の間取り図の座標（1px = 0.125m）で部屋を定義しています。
長屋・新土蔵・表門・裏門・泉水のある庭・弁天と稲荷の祠なども図の配置どおりに置いています。
進路（`RAIL`）が壁を横切る位置には、自動で戸口を開けています。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面とHUD |
| `js/main.js` | 進行・敵AI・フリック判定・カメラ・演出 |
| `js/world.js` | 間取り図から吉良邸を3D生成 |
| `js/characters.js` | 人物モデル（火事装束の浪士、寝間着の家臣、吉良）とポーズ |

| `assets/models/` | 着物と刀の3Dモデル（上記クレジット参照） |
| `vendor/three.module.min.js`, `vendor/addons/` | Three.js r170 と後処理（ブルーム等）のアドオン（MIT License） |

音声と、屋敷・背景の画像はすべてプログラムで生成しています。

## Android アプリ

Capacitor でゲームのファイルをアプリに同梱しています（オフラインで遊べます）。パッケージ名は `jp.techgym.ako`。
ビルドは GitHub Actions（`.github/workflows/android.yml`）で行い、既定ブランチへの push のたびに動作確認用の APK（デバッグ署名・テスト広告）を Release に載せます。

- リリース画面（説明とビルド番号つき）：https://github.com/techgymjp/ako/releases/tag/android-latest
- APK を直接ダウンロード：https://github.com/techgymjp/ako/releases/latest/download/ako.apk
- スマホで読み取る QR コード（リリース画面が開きます）：

  ![APK のリリース画面の QR コード](docs/apk-qr.png)

GitHub Secrets（`ANDROID_KEYSTORE_BASE64` など 4 つ）を登録すると、Google Play 用の署名付き AAB（本番広告）も Artifact に作られます。

| コマンド | 内容 |
| --- | --- |
| `npm run build` | Web 版のファイルを `www/` にまとめる |
| `npm run build:app` | アプリ用（Web 版だけの部分〔テスト用の仕組み・キーボードの案内・無料のやり直しボタン〕を取り除く） |
| `npm run android:sync` | アプリ用にまとめて Android プロジェクトへ反映 |

### 広告（AdMob）

- バナー：トップ・遊び方・一時停止・結果の画面だけ（プレイ中は出さない）
- 全画面広告：討ち入りを始めるとき、トップへ戻るとき、一時停止から再開するとき、結果画面から最初からやり直すとき
- リワード広告：斬られたときに「広告を見て、この戦いからやり直す」（1 回の討ち入りで 5 回まで）。最後まで見たときだけやり直せる
- 本番の広告ユニット ID は `js/ads.js`、AdMob のアプリ ID は `android/app/src/main/res/values/strings.xml` の `admob_app_id`

## ローカルで動かす

ES Modulesを使っているため、HTTPサーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

## GitHub Pages で公開する

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main`、フォルダを `/ (root)` にします。
